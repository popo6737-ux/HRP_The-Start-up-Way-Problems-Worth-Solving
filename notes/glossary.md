# 핵심 용어 정리 (Glossary)

강의에서 등장하는 핵심 개념을 영어 원문 + 한글 설명으로 정리합니다. 강의가 진행되며 계속 업데이트합니다.

| 영어 용어 | 한글 설명 |
|---|---|
| Lean Startup | 최소한의 자원으로 빠르게 가설을 검증하며 제품/사업을 개발하는 방법론 |
| MVP (Minimum Viable Product) | 고객의 반응을 검증하기 위한 최소 기능 제품 |
| Problems Worth Solving | "풀 가치가 있는 문제"를 먼저 검증하라는 강좌의 핵심 메시지 — 해결책보다 문제 정의가 우선 |
| Innovation Accounting | 전통적 재무 지표 대신 학습과 검증 과정을 측정하는 방식 |
| Pivot | 기존 가설이 틀렸을 때 전략을 전환하는 것 |
| Growth Board | 사내 스타트업 포트폴리오를 스타트업처럼 관리하는 거버넌스 체계 |
| Product-Market Fit | 제품이 시장(고객)의 니즈에 충분히 부합하는 상태. 실패 사례 대부분의 공통 원인 (Reading 5) |
| Solution in search of a problem | "문제 없는 해결책" — 시장 니즈 검증 없이 제품부터 만드는 실패 패턴 (Reading 5) |
| Customer Acquisition Cost (CAC) | 고객 1명을 확보하는 데 드는 비용 |
| Collison Installation | Stripe 창업자들이 쓴 즉시 설치 전략 — "베타 써보실래요?" 대신 "노트북 주세요" (Reading 6) |
| Compound Growth | 매주 일정 비율(예: 10%)로 성장하면 1년 뒤 규모가 기하급수적으로 커지는 원리 (Reading 6) |
| Insanely Great | Steve Jobs의 표현 — 초기 스타트업에서는 제품보다 "사용자가 되는 경험" 자체가 극도로 훌륭해야 한다는 개념 (Reading 6) |
| Contained Fire Strategy | 처음부터 넓은 시장이 아닌 좁은 세그먼트에서 critical mass를 만드는 전략 (Reading 6) |
| Pulling a Meraki | 하드웨어 스타트업이 초기에 제품을 직접 손으로 조립하는 전략 (Reading 6) |
| Manager Mode | 조직을 블랙박스로 나누어 위임하는 전통적 경영 방식 (Reading 7) |
| Founder Mode | 창업자가 조직 전반에 직접 관여하는, 매니저 모드와 다른 운영 방식 (Reading 7) |
| Skip-level Meeting | 직속 라인을 건너뛰고 CEO가 실무진과 직접 소통하는 관행 (Reading 7) |
