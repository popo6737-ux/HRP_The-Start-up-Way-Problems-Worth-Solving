# 핵심 용어 정리 (Glossary)

강의에서 등장하는 핵심 개념을 영어 원문 + 한글 설명으로 정리합니다. 강의가 진행되며 계속 업데이트합니다.

| 영어 용어 | 한글 설명 |
|---|---|
| Lean Startup | 최소한의 자원으로 빠르게 가설을 검증하며 제품/사업을 개발하는 방법론 |
| MVP (Minimum Viable Product) | 고객의 반응을 검증하기 위한 최소 기능 제품 |
| Problems Worth Solving | "풀 가치가 있는 문제"를 먼저 검증하라는 강좌의 핵심 메시지 — 해결책보다 문제 정의가 우선 |
| Innovation Accounting | 전통적 재무 지표 대신 학습과 검증 과정을 측정하는 방식 |
| Pivot | 기존 가설이 틀렸을 때 전략을 전환하는 것 |
| Growth Board | 사내 스타트업 포트폴리오를 스타트업처럼 관리하는 거버넌스 체계 |
