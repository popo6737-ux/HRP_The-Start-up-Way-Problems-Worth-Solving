# FoamFit — Lean Startup 프레임워크 재구성

Module 1 리딩(특히 Reading 1: Blank, *Why the Lean Start-Up Changes Everything*)의 개념으로 FoamFit을 재점검합니다. 목표는 "그럴듯한 사업계획서"가 아니라 **"검증된 것과 검증되지 않은 것을 구분한 정직한 현황판"**을 만드는 것.

---

## 1. 지금 우리는 어느 단계인가 — Exploration 단계

Reading 3(Rayport et al.)의 3단계 모델(**Exploration → Extrapolation → Exploitation**) 기준으로, FoamFit은 명백히 **Exploration(탐색)** 단계입니다. 아직 Product-Market Fit조차 검증되지 않았으므로, "카트리지 구독 수익 모델"이나 "3단계 로드맵" 같은 내용은 **현재 검증된 사실이 아니라 미래 가설**임을 스스로 명확히 인식해야 합니다.

---

## 2. 핵심 질문: 지금까지의 설문은 무엇을 검증했는가?

### Problem Validation vs. Solution Validation

Customer Development(Reading 1)에서는 검증을 크게 두 단계로 나눕니다:

| 구분 | 검증하는 것 | FoamFit의 현재 상태 |
|---|---|---|
| **Problem Validation** (문제 검증) | 이 문제가 실제로 존재하고, 고객이 신경 쓸 만큼 중요한가? | **부분적으로 검증됨** — 응답자의 50%가 "물티슈 대안이 있으면 쓰겠다"고 답함 |
| **Solution Validation** (해결책 검증) | 우리가 제안한 *이 구체적 해결책*이 그 문제를 실제로 해결하는가? 고객이 *이것에 대해* 돈을 내고, 쓰고, 다시 찾을 것인가? | **전혀 검증되지 않음** |

### n=18 설문을 냉정하게 뜯어보면

1. **질문 자체가 FoamFit이 아니다.** 설문 문항은 "물티슈 대안이 있다면 쓰겠는가"였지, "화장지를 당기면 자동으로 폼이 분사되는 기계식 모듈을 써보겠는가"가 아니었습니다. 응답자는 FoamFit의 존재 자체를 모른 채 답했습니다.
2. **표본이 매우 작고 편향되어 있다.** n=18은 특정 앱(블라인드) 사용자, 즉 특정 연령·직군에 편중된 표본입니다. 일반화하기 어렵습니다.
3. **응답은 선호(preference)이지 행동(behavior)이 아니다.** "쓰겠다"는 응답과 실제로 지갑을 열거나 낯선 장치를 처음 써보는 행동 사이에는 큰 간극이 있습니다(설문 응답의 사회적 바람직성 편향).
4. **타겟 고객(=실제 구매자)에게 물은 것이 아니다.** FoamFit은 B2B 모델인데, 정작 설문 대상은 최종 사용자(개인)이지 **구매를 결정하는 시설 관리자**가 아닙니다. Blank의 표현을 빌리면, 진짜 "건물 밖으로 나가야 할" 대상은 아직 만나지 않았습니다.

**결론: 지금까지 확인한 것은 "문제가 존재할 가능성이 있다"는 약한 신호(weak signal)뿐이며, 이는 Problem Validation의 초입 단계입니다. Solution Validation은 아직 시작도 하지 않았습니다.**

## 3. Business Model Canvas로 본 FoamFit — 검증됨 vs. 가설

| 캔버스 블록 | 현재 내용 | 검증 상태 |
|---|---|---|
| Customer Segments | 시설 운영자(B2B) + 최종 이용자(B2C 영향) | ⚠️ 가설 — 시설 운영자 인터뷰 없음 |
| Value Proposition | 무전원·모듈형 설치, 물티슈 대비 저비용 | ⚠️ 가설 — 가격 미정, 실사용 경험 미검증 |
| Channels | 디스펜서 제조사 파트너십 | ⚠️ 가설 — 파트너사 접촉 전 |
| Customer Relationships | 카트리지 구독 | ⚠️ 가설 |
| Revenue Streams | 모듈 판매 + 구독 + 파트너십 수익 | ⚠️ 완전 미검증 |
| Key Resources | 기계식 펌프 설계, 폼 포뮬러 | ⚠️ 프로토타입 없음 |
| Key Activities | 파트너십 개발, 제조 | ⚠️ 미착수 |
| Key Partners | 디스펜서 제조사, 폼 OEM | ⚠️ 미접촉 |
| Cost Structure | 언급 없음 | ❌ 전혀 다뤄지지 않음 |

→ 9개 블록 중 **실제로 데이터 기반으로 검증된 블록은 0개**입니다. 이건 나쁜 게 아니라 Exploration 단계 스타트업의 정상적인 모습입니다 — 다만 기획서가 마치 검증된 계획인 것처럼 "로드맵", "수익 구조" 같은 확정적 언어를 쓰고 있는 게 문제입니다.

## 4. MVP 제안 — 지금 무엇을 만들어야 하는가

Blank의 원칙("Get out of the building" + MVP)에 따르면, 다음 프로토타입 전에 카트리지 구독 모델이나 자체 브랜드까지 설계할 필요가 없습니다. 제안하는 MVP 단계:

1. **Concierge MVP (자동화 이전 단계):** 기계식 펌프를 완성하기 전, 시설 관리자 1곳을 찾아 "우리가 하루 한 번 수동으로 디스펜서 옆에 폼 스프레이를 부착/보충해드리겠다"는 형태로 며칠간 운영 — Reading 6(Graham)의 **"Manual" 전략**과 동일한 접근.
2. **단일 기능 프로토타입:** 자체 폼 포뮬러나 Lock 스위치 등 부가 기능 없이, "당기면 분사된다"는 핵심 메커니즘만 작동하는 조악한 프로토타입.
3. **단일 장소 파일럿:** 로드맵의 "휴게소 전체"가 아니라 **단 1개 화장실, 1개 스톨**에서 2주간 실사용 데이터 수집.

## 5. Innovation Accounting — 지금 추적해야 할 지표

전통적 지표(로드맵의 "매출", "수익 구조")는 아직 의미가 없습니다. 대신 학습 검증에 초점을 맞춘 지표가 필요합니다:

| 지표 | 무엇을 배우는가 |
|---|---|
| 시설 관리자 미팅 요청 → 실제 미팅 성사율 | B2B 채널의 실제 진입 장벽 |
| 파일럿 참여 동의를 얻은 시설 수 / 접촉한 시설 수 | Value Proposition이 시설 운영자에게 통하는가 |
| 파일럿 기간 중 Lock 스위치를 끈 사용자 비율 | 실사용자가 기능을 실제로 원하는가 (설문 응답과의 괴리 측정) |
| 파일럿 기간 중 재사용률(같은 사용자가 반복 사용) | 일회성 호기심인지 지속적 니즈인지 구분 |
| 시설 관리자가 자발적으로 재문의/확장 요청하는지 여부 | 진짜 수요 신호(허영 지표가 아닌 실질 지표) |

이런 지표들이 바로 Innovation Accounting이 강조하는 "허영 지표(vanity metric, 예: 설문 동의율 50%)"가 아닌 **실행 가능한 학습 지표(actionable metric)**입니다.

## 6. Pivot 신호 vs. Iterate 신호

| 상황 | 대응 |
|---|---|
| 접촉한 시설 관리자 다수가 "물티슈 문제 자체를 심각하게 여기지 않는다"고 답함 | **Pivot 검토** — 문제 정의 자체를 재검토 (예: 타겟을 오피스 화장실로 좁히거나, 문제를 "청결"이 아닌 "관리비용"으로 재정의) |
| 시설 관리자는 관심 있으나 "가격이 맞지 않는다"고 답함 | **Iterate** — 가격 모델(구독 vs 판매)만 조정 |
| Lock 스위치 사용률이 예상보다 훨씬 높음 (대부분 꺼놓음) | **Iterate** — 기능이 아니라 "왜 꺼놓는지"를 인터뷰로 파악, UX/폼 품질 개선 |
| 디스펜서 제조사 다수가 파트너십에 무관심 | **Pivot 검토** — 유통 전략을 B2B 파트너십에서 직접 시설 영업으로 전환 |
| 타겟 시설 다수가 이미 CWS 같은 종합 위생서비스 업체와 렌탈 계약 중 (`competitive-analysis.md` 1-1 참고) | **Pivot 검토** — "독립 제품 판매"가 아니라 "기존 위생서비스 업체에 폼 모듈을 라이선스/납품하는 B2B2B 모델"로 전환하는 것도 고려. 직접 경쟁보다 기존 벤더의 공급망에 올라타는 편이 현실적일 수 있음 |

## 7. 다음 Customer Development 액션 (건물 밖으로 나가기)

- [ ] 시설 관리자(휴게소/오피스 총무팀) 5~10명과 1:1 인터뷰 — 설문이 아니라 **개방형 질문**으로 진행 (`competitive-analysis.md`의 인터뷰 가이드 참고)
- [ ] 최종 사용자 대상으로 실제 시제품(조악해도 됨)을 보여주고 반응 관찰 — "쓰겠는가"가 아니라 "직접 써보게" 하고 관찰
- [ ] 디스펜서 제조사 최소 2~3곳에 초기 컨택 — 파트너십 반응 자체가 하나의 검증 데이터
